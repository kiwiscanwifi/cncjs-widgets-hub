# Changelog - Controller Console

All notable changes to the Controller Console widget are documented in this file.

## [1.0.0] - 2026-10-30
### Initial Release
- **Intelligent Noise Suppression**: Prefix blacklist and category toggles to filter high-frequency background noise (M119 probe continuity polls, periodic status reports ? / <Idle|...>, and ok confirmations).
- **Peek Mode & Counter**: Real-time counter of suppressed lines with 1-click temporary peek to inspect raw traffic.
- **Command Bar & History**: Up/Down arrow terminal command history buffer with Enter key execution.
- **Color-Coded Stream**: Sent commands (cyan), normal output (neutral), errors/alarms (bold red), and notices (amber).
- **Smart Auto-Scroll**: Auto-scroll with smart manual scroll lock and instant resume button.
- **System Manager Full-Screen Launch**: Launchable in full-screen directly from the System Manager widget.
- **Native Settings Modal**: Custom prefix manager and terminal buffer tuning.
- **Author**: Mark Dyer @ fireCNC.
