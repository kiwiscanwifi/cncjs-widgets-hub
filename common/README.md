# Shared Framework Assets (`/widgets/common/`)

This directory houses the authoritative shared styling assets for the CNCjs Widget Hub ecosystem.

## Assets Overview

| File | Context | Description |
| :--- | :--- | :--- |
| **`widget-framework.css`** | **Workspace (Dark)** | The unified design system for all live workspace widgets (`index.html`). Provides resets, tokens, tactile buttons, DROs, LEDs, and title bar governance. |
| **`settings-common.css`** | **Edit Modal (Light)** | The native CNCjs settings stylesheet for widget configuration dialogs (`settings.html`). Provides native navigation tabs, content wells, and form controls. |

## Documentation
For complete guidelines, class references, and copy-paste code boilerplates, see the **[Styling Guide](../docs/STYLING_GUIDE.md)**.
