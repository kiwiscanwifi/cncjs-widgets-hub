❓ Widget Hub Help & Guide
🔄 Real-Time Workspace Synchronization

Installed widgets sync automatically with CNCjs native Manage Widgets in real time without requiring page refreshes.

📦 Managing Extensions

• Install: Installs the extension on this machine and automatically enables it into your workspace.

• Uninstall: Completely uninstalls the extension from this machine and removes it from your workspace.

• Workspace Panels: To show or hide any installed widget, open CNCjs's native Manage Widgets button in the top bar and check or uncheck it.

• Settings: Click the ⚙️ gear icon in any widget header to configure its options using the native settings popup.

🛠️ Refresh & Maintenance

To reload any widget, click the native Refresh icon (fa-refresh) in its title bar.

🚀 Clean Installation Runbook (Brand New CNCjs Machine)

To deploy this Widget Hub & Native Extension system on a fresh stock CNCjs install:

1. Create Webroot Directory:
sudo mkdir -p /var/www/widgets && sudo chown -R $USER:$USER /var/www/widgets

2. Mount in CNCjs Configuration (~/.cncrc):
Add to "mount" array in ~/.cncrc:
{"route": "/widgets", "target": "/var/www/widgets"}

3. Inject Universal Loader into index.hbs:
In /usr/lib/node_modules/cncjs/dist/cncjs/app/index.hbs, add:
<script src="/widgets/loader.js"></script>

4. Apply Generic Bundle Hooks to main.*.bundle.js:
• Hook 1 (Catalog): n.widgetList.concat(window.CNCjsHooks.getWidgets())
• Hook 2 (Resolver): window.CNCjsHooks.getComponent(n, UP)
• Hook 3 (Defaults): window.CNCjsHooks.getDefaults(widgetId)
• Hook 4 (Modal): Native settings modal with [Cancel] & [Save Changes]
• Hook 5 (Header): Omit redundant enable/disable toggle for managed widgets

5. Restart CNCjs Service:
sudo systemctl restart cncjs

6. Mount Widget Hub:
In CNCjs workspace, click [+] Add Custom Widget → Title: "Widget Hub", URL: "/widgets/widget-hub/"
⚙️ Recommended Server & Reverse Proxy Settings (Resource Optimization)

As widget count and operator tablet devices scale, efficient server resource utilization guarantees zero disconnects and ultra-low telemetry latency:

1. Shared Socket Standard (Zero Overhead):
Custom widgets should share the parent CNCjs native Socket.io connection via window.parent.CNCjsHooks.getSocket() instead of spawning independent io.connect() instances. This enforces 1 socket connection per browser tab, eliminating connection storms, worker process starvation, and redundant serialport room subscriptions.

2. Apache Reverse Proxy (Disable 60s Worker Lockout):
In /etc/apache2/sites-available/cncjs.conf, configure the proxy directive with retry=0 and timeout=3600:
ProxyPass / http://127.0.0.1:8000/ retry=0 timeout=3600 keepalive=on
Why: Apache's default retry=60 blocks all incoming traffic for 60 seconds if a single socket client resets. Setting retry=0 completely eliminates connection blackout freezes.

3. Force WebSocket Direct Transport:
When direct sockets are required for standalone development, always pass { transports: ['websocket'] } to bypass HTTP long-polling holds that tie up Apache prefork workers.

4. Webcam Video Stream Tuning (uStreamer):
Run uStreamer with persistent TCP connections and direct buffer flushing:
ustreamer --persistent --tcp-nodelay --buffers 3 --desired-fps 30

5. Network Physical Demarcation:
For production shop-floor machine control, connect the controller host via wired Ethernet (eth0) rather than Wi-Fi to eliminate PCIe bus latency and RF packet retry stalls during active jobs.
